# My First Backend

My First Backend is a REST API built with Node.js and Express.js. It manages fruit data using a simple object-oriented programming (OOP) approach.

The project allows users to retrieve, create, update and delete fruit records stored in a JSON file.

## Technologies Used
- Node.js – JavaScript runtime environment
- Express.js – Backend framework for handling HTTP requests and routes
- JavaScript – Main programming language
- JSON – Stores fruit data
- REST API – Provides endpoints for performing CRUD operations

## Features
- Retrieve all fruits
- Find an individual fruit by name
- Add new fruits
- Update existing fruit information
- Delete fruits
- Validate fruit names and prevent duplicate entries
- Automatically generate IDs for new fruits

## CRUD Operations
| Operation | HTTP Method | Functionality |
|---|---|---|
| Create | POST | Add a new fruit. |
| Read | GET | Retrieve all fruits or find a specific fruit by name. |
| Update | PUT | Update an existing fruit's information. |
| Delete | DELETE | Remove a fruit. |

## 
This project was created to practise:
- Building a backend application using Node.js and Express
- Understanding REST API architecture
- Implementing CRUD functionality
- Applying object-oriented programming principles
- Separating application logic into models, controllers and routes
- Working with JSON data
